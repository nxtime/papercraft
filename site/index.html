A native canvas that AI agents can drive.

PaperCraft is an infinite-canvas design tool and whiteboard. It runs on your desktop with no account and no cloud, and it serves the Model Context Protocol so Claude Code, Codex and other agents can edit the open canvas, screenshot it and lint it, one undo step per call.

What you get

A real design tool, not a chat window with a canvas bolted on.

Frames, auto layout, components, variables and a hand-drawn whiteboard on one GPU-rendered canvas.

The editor

Layers, canvas, inspector. One native window.

Built in Rust on egui and wgpu. Cached frames take about 3 ms with ten thousand visible layers.

  • Auto layout with gap, padding, hug, fill, wrap and constraints
  • Pen and Bézier editing, boolean operations, gradients and blend modes
  • A command palette over every action, page and layer
Chat mode

Pick an agent. Describe the screen.

A conversation sits next to the canvas. Point at layers with @ mentions or a picked area, and the agent gets a crop with your notes drawn on it.

  • Claude Code and Codex through their CLIs, with your own logins
  • Any ACP agent on your PATH, or the Anthropic API with your key
  • Every run can be reviewed, reverted one change at a time, or accepted
Annotations

Annotate in place. Agents read the notes.

Pin typed notes for rules, behaviour, content and data to any layer, with a template per project. They travel with the design into the handoff spec.

Design systems

Tokens out as CSS, DTCG or Tailwind. Code out as JSX.

Variables with modes and aliases, components that work across projects, and shared libraries you publish, enable and update.

  • Light and dark are modes on one artboard, never copies
  • Lint for contrast, the 4px grid, type scale and touch targets, with auto-fix

Local-first

Your project is a folder on your disk.

Plain JSON you can back up, diff and commit. No account to make and no server to trust.

~/Documents/papercraft/Pulse/
├── project.json        # manifest, variables, components
├── pages/              # one JSON file per page
├── versions/           # named and automatic versions
├── runs/               # agent runs, for review and revert
└── chats/              # chat threads with their tool calls

Atomic autosave

Every write is atomic, and older files are migrated forward when they load.

Works with the app closed

papercraft-cli --offline runs the same tools on the project store, screenshots included.

Keys stay in your OS

API keys live in the system credential store and never in a project file, chat or log.

Connect

Same tools, three ways in.

The MCP server is built into the app and listens on loopback only. Browser requests and foreign hosts are rejected.

Register it once

Start PaperCraft, then add it to your agent.

# Claude Code
claude mcp add --transport http --scope user \
  papercraft http://127.0.0.1:29980/mcp
# Codex
codex mcp add papercraft --url http://127.0.0.1:29980/mcp
# No app running
papercraft-cli call get_screenshot '{"nodeId":"abc123:1"}' \
  --project Demo -o card.png

First run

Windows builds are unsigned, so SmartScreen may ask you to confirm. macOS builds are ad-hoc signed and not notarized: open the app with right-click, Open the first time.

Build from source

Rust 1.95 or newer, then cargo build --release. Linux needs Vulkan or GL and the usual X11 or Wayland libraries.

Status

Alpha, and used daily.

PaperCraft is good for screens, design systems and sketches, and it is not yet a replacement for a mature design tool. The roadmap lists what is missing, in priority order.
